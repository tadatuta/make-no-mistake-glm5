# CineLife - Your Life. The Movie.

An AI-powered web application that transforms your life story into a cinematic experience with a movie poster, title, plot, and characters.

![CineLife Banner](public/og-image.png)

## Features

- 🎬 **AI-Generated Movie Title** - Get a compelling title for your life story
- 🎨 **Custom Movie Poster** - Professional-quality poster generated by AI
- 📖 **3-Act Plot Summary** - Your story structured as a cinematic narrative
- 👥 **Character Descriptions** - You and your loved ones as movie characters
- 🎭 **Genre Classification** - Discover what genre your life story fits
- 📱 **Easy Sharing** - Share your movie on social media or download the poster

## Tech Stack

- **Frontend:** React 18 + Vite + Tailwind CSS
- **Hosting:** Vercel (free tier)
- **Text AI:** OpenAI GPT-4o-mini
- **Image AI:** Replicate FLUX
- **Analytics:** Umami (privacy-focused)

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn
- OpenAI API key (optional, for text generation)
- Replicate API token (optional, for image generation)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/cinelife.git
cd cinelife
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
```bash
cp .env.example .env.local
```

Edit `.env.local` with your API keys:
```env
OPENAI_API_KEY=sk-your-key-here
REPLICATE_API_TOKEN=r8-your-token-here
```

4. Start the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

2. Import the project in [Vercel](https://vercel.com)

4. Deploy!

Or use the Vercel CLI:
```bash
npm i -g vercel
vercel
```

## API Endpoints

### POST /api/generate/text

Generate text content (title, logline, genre, plot, characters).

**Request:**
```json
{
  "type": "title|logline|genre|plot|characters",
  "input": {
    "name": "string",
    "age": number,
    "events": ["string"],
    "challenge": "string",
    "achievement": "string",
    "goal": "string",
    "people": ["string"],
    "mood": "string"
  }
}
```

### POST /api/generate/poster

Generate a movie poster image.

**Request:**
```json
{
  "title": "string",
  "genre": "string",
  "plotSummary": "string"
}
```
